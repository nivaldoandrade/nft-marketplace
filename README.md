# NFT Marketplace

Desafio Frontend — marketplace de NFTs em React + TypeScript com dados simulados (MSW + Socket.IO).

> Documentação completa (setup, cenários de mock, contratos REST, eventos e arquitetura) será adicionada ao longo da implementação.

## Requisitos

- Node.js 22+
- Yarn 1.x

## Setup

```bash
yarn
cp .env.example .env
yarn dev
```

## Scripts

| Comando                       | Descrição                   |
| ----------------------------- | --------------------------- |
| `yarn dev`                    | Servidor de desenvolvimento |
| `yarn build`                  | Build de produção           |
| `yarn preview`                | Preview do build            |
| `yarn typecheck`              | Verificação de tipos        |
| `yarn lint` / `yarn lint:fix` | ESLint                      |
| `yarn format`                 | Prettier                    |
